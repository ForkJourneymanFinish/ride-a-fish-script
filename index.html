FAQ

Frequently asked questions

Quick answers about the Ride a Fish Script and the Windows executor.

Which Windows versions are supported?

The executor runs on Windows 10 and Windows 11 (64-bit). It is a standalone binary, so no additional runtimes or dependencies need to be installed.

Does the script work on multiplayer servers?

Yes. Ride a Fish Script is built specifically for multiplayer: mount states, riding animations, and speed changes are synced across all connected players so everyone sees the same thing.

Can I change the speed boost multiplier?

Absolutely. The speed multiplier, mount height, and animation blend speed are exposed as configurable values at the top of the Lua script. Edit them before loading to match your preference.

Is the script free and open source?

Yes — Ride a Fish Script is completely free and the source is publicly available. You can audit the Lua code, fork the repository, and contribute improvements via the GitHub link in the footer.
